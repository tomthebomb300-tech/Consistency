# Consistency Tracker
A visual reminder of habits, built in python with an Sqlite database for storing habits.

## Controls
- Add habits with the plus on top.
- Edit habits with the edit button to the right of the habit description.
- Remove a habit with the bin button to the right of the habit.
- Select / de-select if a day was complete or not, by clicking the squares on the habit canvas.
